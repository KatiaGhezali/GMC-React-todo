# GMC React To-Do List

## Overview

A simple To-Do List application built with React. It allows users to add, edit, delete, and complete tasks.

Tasks are saved in the browser using localStorage, so they remain available after refreshing or reopening the application in the same browser.

## Features

- Add tasks with a name and description.
- Validate that both fields are filled in.
- Edit existing tasks using a pre-filled form.
- Delete tasks with a confirmation prompt.
- Mark tasks as completed or active.
- Visually distinguish completed tasks from active tasks.
- Persist tasks using localStorage.
- Responsive layout for smaller screens.
